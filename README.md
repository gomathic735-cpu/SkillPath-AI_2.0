# 🧠 SkillPath AI

### AI-Powered Personalized Skill Development Platform

SkillPath AI is a personalized learning and career development platform built using Python and Streamlit. It helps students assess their skills, track their learning progress, identify skill gaps, and explore career opportunities.

## 🚀 Features

- **Dashboard:** Overview of skills, assessments, and performance.
- **Skill DNA:** Understand your skill profile.
- **Skill Proof Lab:** Test skills through assessments.
- **Assessment History:** Track previous assessment results.
- **AI Recommendations:** Get personalized learning suggestions.
- **Performance Analytics:** Visualize learning progress.
- **Career Intelligence:** Explore career preparation suggestions.
- **Adaptive Learning:** Get recommendations based on skill levels.
- **What-If Simulator:** Simulate possible assessment improvements.
- **Resume Analyzer:** Analyze resumes and identify skills.
- **Job Role Matching:** Explore suitable job roles.
- **PDF Report:** Download performance reports.

## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- Plotly
- SQLite
- PyPDF
- Python-docx
- ReportLab

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/gomathic735-cpu/SkillPath-AI_2.0.git
```

### 2. Open the Project Folder

```bash
cd SkillPath-AI_2.0
```

### 3. Install Required Libraries

```bash
pip install streamlit pandas plotly pypdf python-docx reportlab
```

### 4. Run the Application

```bash
streamlit run app.py
```
